# KB Gap Analysis

## When to Use
- Review an area for stale or thin coverage.
- Identify the next highest-value notes to create or expand.
- Find duplication, orphaned notes, or weak linking.

## Procedure
1. Define the area, folder, or topic cluster to audit.
2. Use the [audit checklist](./references/audit-checklist.md) to evaluate coverage and freshness.
3. Group findings into stale notes, thin notes, missing topics, duplication, and taxonomy friction.
4. Rank follow-up work by reader value, risk, and adjacency to existing notes.
5. Recommend the smallest concrete next steps instead of broad restructuring by default.

## Output Expectations
- Audit scope
- Findings by category
- Prioritized backlog
- Suggested target files or folders
- Risks if the gaps remain unaddressed
