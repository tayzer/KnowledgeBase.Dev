# Redis
Date: 2025-11-25
Status: 🟢 Current
Tags: #redis #cache #inmemory #nosql

## 🎯 TL;DR / Quick Reference

**Definition:** An in-memory data structure store used as a cache, database, and message broker.

**When to use:**
- Low-latency caching, leaderboards, pub/sub, and simple key-value storage.

**Key Takeaways:**
- ✅ **Extremely low latency** and rich data structures (lists, sets, sorted sets, hashes).
- ⚡ **Persistence options:** RDB and AOF for durability trade-offs.

---

## 📚 Deep Dive

### Patterns
- Use Redis for Cache-Aside, distributed locks (with caution), and pub/sub patterns.
