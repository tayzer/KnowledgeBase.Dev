# OOP Fundamentals

Date: 2026-06-13
Status: 🟢 Current

## 🎯 TL;DR / Quick Reference

**Definition:** Four core pillars of Object-Oriented Programming that enable modular, maintainable, and extensible code design.

**The Four Pillars:**
1. **[[Encapsulation]]** – Hide internal state; control access through public interfaces.
2. **[[Inheritance]]** – Reuse behavior by extending base classes or implementing interfaces.
3. **[[Polymorphism]]** – Use objects interchangeably through common interfaces or base types.
4. **[[Abstraction]]** – Simplify complexity by exposing only essential details.

**Key Takeaways:**
- ✅ These pillars work together; mastering them unlocks the entire SOLID framework.
- ✅ Polymorphism is the engine; encapsulation is the protection; inheritance is the reuse; abstraction is the simplification.
- ⚠️ Inheritance can become problematic if overused; favor composition and interfaces (see [[Polymorphism]]).
