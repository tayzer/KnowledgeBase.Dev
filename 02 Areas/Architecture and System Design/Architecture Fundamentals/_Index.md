# Architecture Fundamentals

## Quick Reference

This category covers Quality Attributes, Modularity and Boundaries, Coupling and Cohesion, Dependencies, and more. Published notes and narrower categories are linked below.

## Category Boundary

Use this category for architecture concepts and failure smells, including service location and distributed coupling; detailed service lifetimes belong in Backend Engineering. The planned terms below are plain text until a canonical note is published.

## Published Notes

- [[Distributed Monolith|Distributed Monolith]] - A distributed monolith is a system split into multiple deployables but still tightly coupled in data, release cadence, runtime behavior, or ownership.
- [[Service Locator|Service Locator]] - A pattern where classes pull dependencies from a global or ambient container (`Resolve<T>()`) instead of receiving them explicitly.
