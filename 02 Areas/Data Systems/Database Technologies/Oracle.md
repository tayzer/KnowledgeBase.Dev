# Oracle

## Quick Reference

**Definition:** Oracle Database is a relational database with transactional, security, and partitioning features that vary by release and edition.

**When to use:**
- Applications whose required Oracle capabilities are available in the selected release, edition, deployment, and licence.

**Key Takeaways:**
- **Feature availability** depends on release, edition, and licensed options.
- Caution: **Licensing and operations:** check licence terms, support, deployment, and maintenance effort.

**Limit:** Capabilities and licensing vary by Oracle release, edition, and contract.

---

## Selection checklist

Name the Oracle Database release and edition. Check partitioning, security, high availability, support, and licence entitlements against official docs. Benchmark representative workloads and plan backup/recovery before selecting it.
