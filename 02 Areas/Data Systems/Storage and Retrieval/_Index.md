# Storage and Retrieval

## Quick Reference

Use this category for object storage and physical retrieval structures. Logical data modeling belongs in Data Models and Query Languages.

## Published Notes

- [[Amazon S3|Amazon S3]] - AWS object storage service for durable, scalable storage of files, blobs, backups, archives, and data-lake assets.
- [[Azure Blob Storage|Azure Blob Storage]] - Microsoft Azure object storage service for unstructured data such as files, media, backups, logs, and analytics inputs.
- [[B-Trees|B-Trees]] - A B-tree is a balanced, page-oriented search-tree family commonly used for ordered indexes and storage on block devices.
- [[Cloud Storage Services|Cloud Storage Services]] - Managed cloud services for durable unstructured data, usually exposed through object-storage APIs rather than database tables or POSIX filesystem semantics.
- [[Google Cloud Storage|Google Cloud Storage]] - Google Cloud's managed object storage service for durable, scalable storage of files, backups, datasets, and application assets.
- [[LSM Trees|LSM Trees]] - An LSM tree is a log-structured storage design that batches writes into sorted immutable files and reorganises them through compaction.
- [[Storage Engines|Storage Engines]] - A storage engine is the component that persists records and provides the physical access paths used by a database or data store.
