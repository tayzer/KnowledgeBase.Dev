# Data Models and Query Languages

## Quick Reference

Use this category for logical data shapes, query languages, and access patterns; product-specific operation belongs in Database Technologies.

## Published Notes

- [[Data Modeling|Data Modeling]] - The practice of shaping data structures, relationships, constraints, and access paths so a system can store and retrieve information safely and usefully.
- [[NoSQL Databases|NoSQL Databases]] - Non-relational databases optimized around specific data models such as document, key-value, wide-column, graph, or in-memory storage.
- [[Relational Databases|Relational Databases]] - Databases that organize data into tables, relationships, constraints, and SQL queries, with transactional and isolation guarantees dependent on engine and configuration.
- [[SQL Joins and Indexes|SQL Joins and Indexes]] - Joins combine rows across related tables; indexes speed up data access paths for filters, joins, sorting, and lookups.
