# Analytics and Data Processing

## Quick Reference

Use this category for analytical data platforms and processing. Operational database internals and transaction design belong in their Data Systems categories.

## Published Notes

- [[Amazon Redshift|Amazon Redshift]] - AWS managed data warehouse optimized for analytic workloads over large datasets.
- [[Data Lakes|Data Lakes]] - A data lake stores large volumes of raw, semi-processed, and curated data, commonly on object storage, for analytics, machine learning, and downstream processing.
- [[Data Warehouses|Data Warehouses]] - Data platforms primarily designed for analytical queries over integrated datasets; transactional capabilities vary by product.
- [[Google BigQuery|Google BigQuery]] - Google Cloud's serverless analytical data warehouse for large-scale SQL querying over datasets used in reporting, BI, and data analytics.
- [[Snowflake|Snowflake]] - Cloud-native data warehouse with separation of storage and compute, supporting SQL; multi-cluster concurrency depends on edition and configuration.
