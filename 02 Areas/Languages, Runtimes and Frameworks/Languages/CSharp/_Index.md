## Published Leaf Extensions

### Async and Concurrency
- [[Immutable and Concurrent Collections|Immutable and Concurrent Collections]] - Immutable collections avoid in-place mutation by producing updated versions, while concurrent collections are designed for safe multi-threaded coordination over shared state.

### Generics
- [[Generic Constraints|Generic Constraints]] - Generics provide type-safe reusable code. Constraints limit allowable type parameters (e.g., `where T : class`, `struct`, `new()`, base types, interfaces).

### Language Fundamentals
- [[Access Modifiers|Access Modifiers]] - Access modifiers in C# control where types and members can be used, shaping encapsulation and API boundaries.
- [[CSharp Fundamentals|CSharp Fundamentals]] - Hub page for foundational C# and .NET concepts that show up repeatedly in everyday application code.
- [[Delegates, Events, and Actions|Delegates, Events, and Actions]] - Delegates are type-safe function pointers; `Action` and `Func` are common delegate types; events are a publisher/subscriber pattern built on delegates.
- [[Expression-Bodied Members|Expression-Bodied Members]] - Concise syntax for single-expression members (methods, properties, constructors, finalizers) using `=>`.

### LINQ
- [[LINQ|LINQ]] - A uniform query syntax in C# to retrieve and manipulate data from different sources (collections, databases, XML) using a consistent model.

### Type System
- [[Collection Types|Collection Types]] - .NET collection types model different data shapes and access patterns such as ordered lists, key-value maps, sets, queues, and stacks.
- [[Dictionary|Dictionary]] - `Dictionary<TKey, TValue>` stores key-value pairs for fast lookup by key.
- [[HashSet|HashSet]] - `HashSet<T>` stores unique values and is optimized for membership checks and set operations.
- [[List|List]] - `List<T>` is a growable, ordered collection backed by an array and optimized for indexed access and append-heavy workloads.
- [[Nullable Reference Types|Nullable Reference Types]] - A C# language feature that distinguishes nullable (`string?`) and non-nullable (`string`) reference types at compile time to reduce null-reference bugs.
